# Week 1 — Foundations of Applied AI

The opening week: what an AI engineer does, how generative AI fits into software
systems, and the fundamentals (tokens, context windows, temperature) — ending
with everyone writing and running their first LLM-powered tool.

## Contents

```
slides/          Lecture deck (Sessions 1 & 2)
session-1-lab/   Hands-on coding lab — build "AskBot", a working LLM CLI
```

## Sessions

- **Session 1 — Hands-on lab:** students build AskBot from scratch (see `session-1-lab/`).
- **Session 2 — LLM fundamentals:** tokens, context windows, temperature, model families, and the API in depth (covered in the deck).

## Learning goals

- Describe the AI engineer (developer) role and the LLM application stack.
- Call a real LLM through an OpenAI-compatible API from your own code.
- Explain tokens, context window, and temperature — and why the model is stateless.
- Apply basic production practices: error handling, retries, token tracking.

Start with `session-1-lab/README.md` for setup and the lab walkthrough.
